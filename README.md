# 物理实验室 · Physics Lab

浏览器端 2D 力学 / 电磁场交互模拟器。选中物体后，右侧 **运动分析 · 参数方程** 会根据当前场与受力自动识别运动类型（圆周、正交电磁场摆线、电场类平抛、重力抛体等），给出符号 + 数值形式的轨迹参数方程，并可在画布上叠加解析轨迹虚线。

## 开发

```bash
npm install
npm run dev
```

```bash
npm run build
npm run test:analysis
```

## 发布为哔哩哔哩 Toy

```bash
npm run pack:toy
```

入口 `index.html` 受平台 1MB 限制，因此该构建会把 JS、CSS、字体拆到 `assets/` 独立文件，只保留约 6KB 的 HTML。产物在 `publish/`：

- `Physics-toy.zip`：上传包，压缩包根目录直接包含 `index.html` 和 `assets/`
- `icon.png`：Toy 图标 500×500
- `cover.jpg`：封面 1200×900

- **搭建**：小球 / 带电粒子 / 滑块、地面、挡板、斜面、匀强 E/B、点电荷、弹簧、轻绳、轻杆
- **实验库**：34 个经典模型（抛体、碰撞、反冲、牛顿摆、竖直圆周、阻尼与受迫振动、耦合振子、双摆、行星轨道、宇宙速度、双星、三体 8 字形、速度选择器、质谱仪、回旋加速器、卢瑟福散射等），每个附原理卡片：说明、关键公式与可尝试的改动
- **积分**：Boris 蛙跳（二阶、辛），磁场中能量严格守恒；轻杆用 SHAKE 约束，双摆 15 s 能量漂移 < 0.01%
- **万有引力**：物体之间可开启 \(F = Gm_1m_2/(r^2+\varepsilon^2)\)；单中心问题自动套用开普勒轨道分析
- **能量账本**：不选中物体时显示系统动能、重力/弹性/静电/引力势能、总动量，以及电场力与外力做功；能量曲线中 E − W 水平即说明只剩保守力
- **场引擎**：`FieldSystem` 统一采样 E/B/φ（默认三维库仑 \(1/r^2\)）；RK4 电场线；可选 \(1/r\) 线电荷截面；场参数可写成随时间变化的公式（如回旋加速器的方波电场）
- **分析**：与选中物体运动状态绑定的参数方程（LaTeX + MathQuill）；图像页支持 v–t、a–t、Ek–t、轨迹与 vx–x / vy–y 相图
- **界面**：暖色纸面 + 衬线标题的简约风格，深色模式跟随系统；移动端底部导航
