# 物理实验室 · Physics Lab

浏览器端 2D 力学 / 电磁场交互模拟器。选中物体后，右侧 **运动分析 · 参数方程** 会根据当前场与受力自动识别运动类型（圆周、正交电磁场摆线、电场类平抛、重力抛体等），给出符号 + 数值形式的轨迹参数方程，并可在画布上叠加解析轨迹虚线。

## 开发

```bash
npm install
npm run dev
```

```bash
npm run build
npm run test:analysis
npm run test:physics   # 物理回归测试（需要 Chromium）
npm run test:ui        # 界面回归测试（需要 Chromium）
```

- **搭建**：小球 / 带电粒子 / 滑块、地面、挡板、斜面、匀强 E/B、点电荷、弹簧、轻绳、轻杆
- **实验库**：34 个经典模型（抛体、碰撞、反冲、牛顿摆、竖直圆周、阻尼与受迫振动、耦合振子、双摆、行星轨道、宇宙速度、双星、三体 8 字形、速度选择器、质谱仪、回旋加速器、卢瑟福散射等），每个附原理卡片：说明、关键公式与可尝试的改动
- **积分**：Boris 蛙跳（二阶、辛），磁场中能量严格守恒；轻杆用 SHAKE 约束，双摆 15 s 能量漂移 < 0.01%
- **万有引力**：物体之间可开启 \(F = Gm_1m_2/(r^2+\varepsilon^2)\)；单中心问题自动套用开普勒轨道分析
- **能量账本**：不选中物体时显示系统动能、重力/弹性/静电/引力势能、总动量，以及电场力与外力做功；能量曲线中 E − W 水平即说明只剩保守力
- **场引擎**：`FieldSystem` 统一采样 E/B/φ（默认三维库仑 \(1/r^2\)）；RK4 电场线；可选 \(1/r\) 线电荷截面；场参数可写成随时间变化的公式（如回旋加速器的方波电场）
- **分析**：与选中物体运动状态绑定的参数方程（LaTeX + MathQuill）；图像页支持 v–t、a–t、Ek–t、轨迹与 vx–x / vy–y 相图
- **元素体系**：每类元素的属性（名称、符号、单位、合法范围、跨字段约束如 μₛ ≥ μ）集中定义在一份 Schema 中，检视栏、输入校验与导入修复都由它生成；每个元素附派生量（形变量、弹力、回旋周期、临界摩擦因数等）与物理模型说明
- **轨迹**：按模拟时间等间隔采样（与缩放无关，碰撞拐点额外采样）；频闪点；数值预测用同一引擎积分，与实际运行逐步一致；解析解在首次接触表面处截断；悬停读数、点击钉住标记点（随曲线自动更新）
- **数值方法**：固定步长 + 累加器，结果与帧率无关、可复现；子步内推进时间；接触用 Gauss–Seidel 迭代，矩形用分离轴定理，摩擦区分静/动并修正蠕滑
- **回归测试**：`npm run test:physics` 在真实浏览器中核对 88 项（能量守恒、预测 = 实际、碰撞/斜面/静摩擦/牛顿摆/质谱仪等理论值）
- **手机壳**：全幅画布，顶栏（文档名、时间、播放、重置、撤销），底栏五个入口（画布 / 添加 / 对象 / 分析 / 实验）。属性在选中物体后以一张表单展开。同一份命令表同时驱动快捷键和「实验」里的扁平操作列表。可安装为 PWA（添加到主屏幕，离线打开）
- **文档**：开始页（新建预设、最近文档缩略图、37 个模板）、新建文档对话框、本地文档库（保存 / 另存为 / 重命名 / 删除）、未保存标记与关闭前询问、刷新后恢复；导出 PNG（1× / 2×）、WebM 视频、CSV 运动数据、场景文件
- **选择与层级**：多选（Shift / Ctrl）、选框、编组（单击选整组、双击进组）、锁定、隐藏、排列（置顶 / 上移 / 下移 / 置底）、对齐与分布、多选共同属性编辑；图层树「编组 → 对象 → 连接件 / 矢量」，可拖动排序与重命名
- **刚体转动**：矩形与小球可转动、滚动、倾倒（`src/engine/rigid.js`，两阶段冲量求解、两点块求解、静 / 动摩擦）
- **交互**：撤销 / 重做（带操作名，删除、清空、载入后可在提示条里一键撤销）；时间轴回看（暂停后拖动或用 `,` `.` 逐帧）；运行中可抓住物体甩出；悬停高亮与放置预览；方向键微调、Alt 关闭吸附、1–9 切换添加工具、Ctrl+C/V 粘贴到鼠标处；拖动参数标签即可调节数值；触控板双指平移、捏合缩放
- **界面**：暖色纸面 + 衬线标题的简约风格，深色模式跟随系统；移动端底部导航
