# 物理实验室 · 架构说明

## 分层

| 位置 | 内容 | 自测 |
| --- | --- | --- |
| `src/engine/rigid.js` | 刚体接触与冲量求解（含转动、静/动摩擦、两点块求解） | `npm run test:rigid` |
| `src/engine/fields/*` | 场系统与电场线 | `npm run test:fields` |
| `src/engine/forceExpr.ts` | 公式：物体引用 `小球2.vx`、全局变量、显示项本地量、未知名字检测 | `npm run test:expr` |
| `src/analysis/motionAnalysis.ts` | 运动类型识别与参数方程 | `npm run test:analysis` |
| `src/app/display/overlayTypes.js` | 显示项类型表、默认值、清洗、旧文档迁移 | — |
| `src/app/simulator.js` | 应用：场景、积分、渲染、交互、面板、命令、文档 | `test:physics` · `test:ui` |

## 文档模型（version 4）

```
{ settings, objects, groups, vars, overlays, view, info: { key, recommend } }
```

- **vars**：全局变量（Desmos 式）。写成数字的变量是滑块（最小 / 最大 / 步长 / ▶ 往返播放），也可以写表达式。
  任何 ƒ 公式里直接写变量名；公式里出现不存在的名字时，输入框下方给出「＋ 创建变量」按钮。改名会同步改所有公式。
- **overlays**：显示项。画布上除对象本身外的一切（速度、加速度、动量、合力、受力分析、外力、自定义矢量、
  已走轨迹、预测轨迹、解析轨迹、频闪点、名称、数值标签、初始位置、电场线）都是一条显示项，
  **默认一条都没有**。每条可设对象（全部 / 选中 / 某物体）、颜色、比例（或自动）、是否标数值与分量。
  自定义矢量与数值标签用公式，可用 `ax ay a omega ang Ek Ep px py p Fx Fy F` 等本物体量。
- **info.recommend**：模板的推荐显示，在教学卡片 / 显示面板里一键启用。

旧文档（version ≤ 3 的全局显示开关）在读入时转换成等效的显示项。

## 关键约定

1. **编辑手柄 ≠ 显示**：拖初速度 / 外力的手柄只在选中单个未锁定物体、暂停时出现，且总画在物体当前位置；
   v₀ 手柄只在 t = 0 出现（不会在运行后残留在初始位置）。
2. **瞬时动力学**：暂停时用同一个引擎从当前状态试走一个子步再还原，得到加速度、支持力、摩擦力、杆的约束力；
   运行中用上一帧的结果。所以 t = 0 也能显示加速度与受力，并与实际运行一致。
3. **数值预测 = 实际运行**：固定步长，预测与运行逐步一致（逐位相同）。
4. **拾取模式**：需要“指向某个对象”的字段（外力指向、显示项对象、公式里的物体引用）旁有 ⌖，
   点一下即可在画布上点选对象（像创建轻杆时一样），可选对象高亮，Esc / 右键取消。
5. **一处定义**：属性规范（SCHEMA）、命令（CMD / MENUS）、显示项类型（OVERLAY_TYPES）各自只有一张表。界面是五入口的手机壳；MENUS 被摊平进「实验」列表，不再渲染成菜单栏。
6. **可测**：`window.__physim` 提供稳定的测试接口。
